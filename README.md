## 🚀 Khởi Chạy & Đưa Lên Online Miễn Phí (Cloud & Mobile PWA)

### Cách 1: Đưa Lên Vercel (Khuyên dùng - 30 giây có link vĩnh viễn)
1. Tải ứng dụng hoặc tạo tài khoản miễn phí tại [Vercel.com](https://vercel.com).
2. Kéo thả trực tiếp thư mục `Web_Học_TA_TN` hoặc kết nối với repository GitHub của bạn.
3. Bấm **Deploy**. Vercel sẽ tự động nhận diện file `vercel.json` và cấp cho bạn một đường link HTTPS tốc độ cao vĩnh viễn (ví dụ: `https://autopilot-study.vercel.app`).

### Cách 2: Đưa Lên Netlify (Kéo-Thả 1 Cú Chuột)
1. Truy cập [app.netlify.com/drop](https://app.netlify.com/drop).
2. Kéo thả toàn bộ thư mục `Web_Học_TA_TN` vào ô upload. Web sẽ online ngay lập tức với HTTPS và hỗ trợ Service Worker PWA.

### Cách 3: Chạy Cục Bộ (Local Machine)
1. Mở terminal tại thư mục `Web_Học_TA_TN`.
2. Khởi chạy:
   ```bash
   python -m http.server 8080
   ```
3. Truy cập: `http://localhost:8080`
